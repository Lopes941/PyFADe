How to install
=======================

Pre-requisites
------------------

PyFADe requires the following components to run:

* C and C++ compiler
* Python >= 3.8
* Pybind11

It also requires the following Python libraries:

* numpy
* scipy
* matplotlib
* pandas
* pmdarima
* PyWavelets


Installing with pip
---------------------

PyFADe is available on `PyPI <https://pypi.org/project//>`_, and can be easily installed by running on a terminal:

.. code-block:: bash

    pip install pyfade

PyFADe is available on Windows, MacOS and Linux.


Custom Installation
---------------------

For custom properties, one should download the source code at `GitHub <https://github.com/RL2-SP3/PD-3.6>`_. You can install it using:

.. code-block:: bash

    pip install .

Custom properties are work in progress. This library is compatible with CUDA.
