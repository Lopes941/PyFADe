About PyFADe
====================

The Python Failure and Anomaly Detection on time series Library (PyFADe) is an open source library for Finite Element Method (FEM) definitions and solvers.

It is a work in progress from researchers from the School of Mechanical Engineering (also `FEM <https://www.fem.unicamp.br/>`_) from Universidade Estadual de Campinas, in Brazil (`UNICAMP <https://www.unicamp.br/>`_). The main contributor is Asst. Prof. Heitor Nigro Lopes.

The source code for PyFADe is available on `GitHub <https://github.com/RL2-SP3/PD-3.6>`_.
