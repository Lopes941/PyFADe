.. _reference_feature_and_groups:

Features and Feature Groups
===========================

Features represent the data calculated within each rolling window, which are typically organized into **Feature Groups**. 

For example, the :ref:`ContinuousStatistics <continuous_statistics>` Feature Group calculates both a rolling mean and a rolling standard deviation (see :ref:`reference_group_module` for a detailed example).

Each Feature Group may carry **Requirements**, meaning that it automatically activates another dependent group if it has not been previously added to the pipeline.

Furthermore, Feature Groups can be configured via parameters. These configuration parameters automatically carry over to any downstream Feature Groups that require them.

.. note::
   If you wish to implement your own custom Feature or FeatureGroup, please refer to :ref:`reference-own_features`.

---

Implemented Feature Groups
--------------------------

.. _continuous_statistics:

ContinuousStatistics
~~~~~~~~~~~~~~~~~~~~
A Feature Group that calculates basic statistical characteristics for the current window.

**Computed Features:**

Mean
    The mathematical mean (average) value of the window.

StdDev
    The standard deviation of the window, measuring data dispersion.

**Requirements:**
    *None.*

**Parameters:**
    *None.*

---

.. _matrix_profile:

MatrixProfile
~~~~~~~~~~~~~
A Feature Group that calculates the matrix profile for the current window to identify structural similarities or anomalies.

**Computed Features:**

MatProfileVal
    The value of the Matrix Profile.

MatProfileInd
    The index of the closest non-self match for the current window.

**Requirements:**
    * :ref:`ContinuousStatistics <continuous_statistics>`

**Parameters:**

use_cuda : bool, default: False
    Set up calculation to use the CUDA framework. If CUDA is not detected or supported on the host machine, the execution automatically falls back to the CPU.

left_only : bool, default: True
    If true, the closest match lookup will only match windows from timestamps *before* the current window (causal matching).

skip_start : int, default: 0
    Number of windows to ignore before starting Matrix Profile calculations. Useful for avoiding artificial spikes on initial windows when ``left_only`` is True.

quantile_threshold : double, default: 0.0 (between 0 and 1)
    Zeroes all values before the set quantile. Used to isolate and highlight anomalies.

exclusion_zone_ratio : double, default: 0.5
    Ratio between the size of the exclusion zone and the window size. A value of 0.5 creates an exclusion zone equal to the size of the rolling window.

---

.. _k_profile_val:

KProfileVal
~~~~~~~~~~~
A Feature Group that calculates the k-dimensional profile for the current window to identify multi-dimensional structural similarities or anomalies.

**Computed Features:**

KProfileVal
    The value of the K-Dimensional Profile.

KProfileInd
    The index of the closest non-self match for the current window.

**Requirements:**
    * :ref:`MatrixProfile <matrix_profile>`

**Parameters:**
    Inherits all parameters configuration from its requirement, :ref:`MatrixProfile <matrix_profile>`. No additional unique parameters.

---

.. _wavelet_profile:

WaveletProfile
~~~~~~~~~~~~~~
A Feature Group that calculates the matrix profile using various wavelet decomposition strategies.

**Computed Features:**

WaveletMP
    The value of the Matrix Profile generated by the chosen wavelet strategy.

**Requirements:**
    *None.*

**Parameters:**

wavelet_total_level : int, default: 3
    The total depth/level of the wavelet decomposition.

wavelet_aggregate_level : int, default: 1
    The level of aggregation used for the Matrix Profile calculation.

wavelet_type : str, default: "haar"
    The mother wavelet type. See the *PyWavelets* library documentation for an exhaustive list of available options.

wavelet_analysis_type : str, default: "kp"
    Specifies the structural analysis strategy applied to the wavelet decomposition:

    kp
        Calculates the ``wavelet_total_level`` decomposition and aggregates the output using the K-Dimensional Profile at the designated ``wavelet_aggregate_level``.
    diff
        Calculates the Matrix Profile of the absolute difference between the original signal and its ``wavelet_total_level`` reconstruction.
    denoise
        Denoises the underlying data using wavelet thresholding prior to calculating the Matrix Profile.

wavelet_denoise_threshold : double, default: 0.05
    The hard/soft threshold limit applied to the wavelet coefficients for noise removal. Only evaluated when ``wavelet_analysis_type`` is set to ``"denoise"``.

use_cuda : bool, default: False
    Set up calculation to use the CUDA framework. If CUDA is not detected or supported on the host machine, the execution automatically falls back to the CPU.

left_only : bool, default: True
    If true, the closest match lookup will only match windows from timestamps *before* the current window (causal matching).

skip_start : int, default: 0
    Number of windows to ignore before starting Matrix Profile calculations. Useful for avoiding artificial spikes on initial windows when ``left_only`` is True.

quantile_threshold : double, default: 0.0 (between 0 and 1)
    Zeroes all values before the set quantile. Used to isolate and highlight anomalies.

exclusion_zone_ratio : double, default: 0.5
    Ratio between the size of the exclusion zone and the window size. A value of 0.5 creates an exclusion zone equal to the size of the rolling window.
